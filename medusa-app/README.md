# AVEART Medusa

Standalone Medusa v2 application for the AVEART commerce admin and API.

## Railway

- Root directory: `/medusa-app`
- Build command: `npm install && npm run build`
- Start command: `npm run start`
- Port: `9000`
- Required variables: `DATABASE_URL`, `JWT_SECRET`, `COOKIE_SECRET`, `STORE_CORS`, `ADMIN_CORS`, `AUTH_CORS`.

This application is intentionally separate from the Medusa framework source tree in the repository root.
